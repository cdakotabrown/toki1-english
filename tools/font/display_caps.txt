# Original letterforms drawn as geometric shapes by hand for this file; not
# traced from, derived from or measured against any existing typeface or any
# retail game art.  Only the STYLE the game applies to the original kanji
# (stroke weight, gold ramp, dark keyline) was looked at, as a brief.
#
# Format (tools/patch/artface.py renders it):
#   glyph <char> adv <units>     a capital in a 100-unit cap-height box,
#                                x to the right, y DOWN, baseline y = 100
#   rect x0,y0 x1,y1             a filled rectangle
#   poly x,y x,y x,y ...         a filled simple polygon
#   ring cx,cy rx,ry wx,wy a0,a1 an elliptical band: outer radii rx,ry,
#                                band thickness wx,wy, angles a0..a1 in
#                                degrees (0 = right, 90 = DOWN, 180 = left,
#                                270 = up; a1 > a0 goes clockwise on screen)
